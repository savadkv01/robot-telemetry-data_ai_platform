# Stage 4 — ROS2 + Gazebo Setup

This stage implements:
- ROS2 workspace packages
- Robot URDF model
- Gazebo simulation launch
- Telemetry topic publishers for `/imu`, `/odom`, `/battery_state`, `/scan`

## Implemented files

- `robotics/ros2_ws/src/robot_description/urdf/telemetry_bot.urdf.xacro`
- `robotics/ros2_ws/src/robot_description/launch/sim.launch.py`
- `robotics/ros2_ws/src/telemetry_sim/telemetry_sim/battery_publisher.py`

## 1) Install ROS2 + Gazebo (WSL Ubuntu 22.04)

```bash
sudo apt update
sudo apt install -y locales software-properties-common curl
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

sudo add-apt-repository universe -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

sudo apt update
sudo apt install -y ros-humble-desktop ros-humble-gazebo-ros-pkgs ros-dev-tools

echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

## 2) Build workspace

```bash
cd ~/robot-telemetry-platform/robotics/ros2_ws
source /opt/ros/humble/setup.bash
colcon build
source install/setup.bash
```

## 3) Launch simulation

```bash
cd ~/robot-telemetry-platform/robotics/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch robot_description sim.launch.py
```

## 4) Inspect telemetry topics

Open another terminal:

```bash
source /opt/ros/humble/setup.bash
source ~/robot-telemetry-platform/robotics/ros2_ws/install/setup.bash

ros2 topic list
ros2 topic echo /imu
ros2 topic echo /odom
ros2 topic echo /battery_state
ros2 topic echo /scan
```

## 5) Check message rates

```bash
ros2 topic hz /imu
ros2 topic hz /odom
ros2 topic hz /battery_state
ros2 topic hz /scan
```

## 6) RViz visualization

```bash
source /opt/ros/humble/setup.bash
rviz2
```

In RViz add displays:
- `LaserScan` topic `/scan`
- `Odometry` topic `/odom`
- `IMU` topic `/imu`

## Notes

- `/imu` and `/scan` are generated by Gazebo sensor plugins.
- `/odom` is generated by Gazebo P3D plugin.
- `/battery_state` is generated by Python ROS2 node `battery_publisher` started by the launch file.
